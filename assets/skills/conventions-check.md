## 检查项

### 命名规范
- 组件文件使用 PascalCase
- 工具函数使用 camelCase
- 常量使用 UPPER_SNAKE_CASE
- 布尔值使用 is/has/can 前缀

### 项目结构
\`\`\`
src/
├── components/   # UI 组件
├── hooks/        # 自定义 Hooks
├── utils/        # 工具函数
├── types/        # 类型定义
└── constants/    # 常量与配置
\`\`\`

### 代码格式
- 缩进 2 空格
- 单引号
- 行尾分号
- 行宽 100 字符
