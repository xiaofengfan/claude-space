## 提交规范
\`\`\`
<type>(<scope>): <subject>

<body>
\`\`\`

### Type 类型
- feat: 新功能
- fix: 修复 Bug
- docs: 文档
- style: 代码格式
- refactor: 重构
- perf: 性能优化
- test: 测试
- chore: 构建/工具
- ci: CI 配置

### 分支规范
- 功能分支: feature/<name>
- 修复分支: fix/<name>
- 热修复: hotfix/<version>
- 发布分支: release/<version>
