## 快速入门

### 第一步：打开知识图谱

**方式一**：点击左侧 ActivityBar 的 🕸️ **知识图谱** 图标

**方式二**：顶部菜单栏 → 知识 → 🕸️ 知识图谱

### 第二步：分析项目

左侧栏点击 **🔍 分析** 按钮，系统会自动扫描项目并生成图谱。

### 第三步：查看图谱

点击左侧栏的 **🕸️ 图谱** 或顶部模式栏的 **🕸️ 图谱** 标签，进入全屏图谱视图。

## 项目分析

### 自动扫描分析

点击 **🔍 分析** 后，系统会：

1. **识别项目类型** — 前端/后端/全栈/Electron 等
2. **功能分类** — 自动将目录归类为：
   - 🏗️ **核心业务** — `src/`, `app/`, `services/` 等
   - 🔗 **API / 接口** — `api/`, `routes/`, `controllers/` 等
   - 🗄️ **数据层** — `db/`, `models/`, `migrations/` 等
   - 🎨 **UI / 前端** — `components/`, `pages/`, `views/` 等
   - ⚙️ **配置** — `config/`, `env/` 等
   - 🧪 **测试** — `test/`, `spec/` 等
   - 🔧 **工具 / 脚本** — `scripts/`, `utils/`, `tools/` 等
   - 📦 **基础设施** — `docker/`, `deploy/`, `k8s/` 等
   - 📖 **文档** — `docs/`, `guide/` 等
3. **实体关系** — 每个分类创建主实体 + 关键文件子实体

### 实体类型

| 图标 | 类型 | 含义 |
|------|------|------|
| 📦 | module | 功能模块 |
| 📄 | file | 代码文件 |
| 🏷️ | class | 类 |
| ⚡ | function | 函数 |
| 🔌 | interface | 接口 |
| 🔗 | api | API 路由 |
| 🗄️ | database | 数据库/Schema |
| ⚙️ | config | 配置文件 |
| 🧩 | pattern | 设计模式 |
| 💡 | concept | 概念/架构决策 |
| 🧪 | test | 测试 |
| 📜 | script | 脚本/工具 |

### 关系类型

| 关系 | 含义 |
|------|------|
| contains | 包含 |
| depends_on | 依赖 |
| calls | 调用 |
| extends | 继承 |
| implements | 实现 |
| imports | 导入 |
| references | 引用 |
| configures | 配置 |

## AI 智能分析

点击 **🤖 AI 分析** 按钮，打开 AI 分析对话框。

### ✉️ 发送分析指令（第一个标签页）

选择分析模板，系统会将结构化的 Prompt 发送到 Chat 对话中，Claude 会根据指令分析项目。

**5 种分析模板：**

#### 🔭 项目全景分析
```
分析项目整体架构、技术栈、核心模块和依赖关系
→ Claude 返回 JSON: { entities: [...], relations: [...] }
```

#### 🧩 模块分解
```
深入分析各模块的内部结构、职责和交互
→ Claude 返回 JSON: { entities: [...类/函数/接口], relations: [...] }
```

#### 🌊 数据流分析
```
追踪数据流向：API → Service → DB，标注数据模型
→ Claude 返回 JSON: { entities: [...], relations: [...], dataFlow: [...] }
```

#### 🔗 API 路由分析
```
提取所有 API 路由、请求方式、参数和响应
→ Claude 返回 JSON: { entities: [...API路由], relations: [...] }
```

#### ✏️ 自定义分析
```
自由输入分析指令，AI 解析后自动提取到图谱
```

### 使用流程

1. 点击 **🤖 AI 分析**
2. 选择分析模板（如「项目全景分析」）
3. 点击 **📤 发送到 Chat**
4. Claude 在 Chat 中接收指令并开始分析
5. Claude 会使用 Read/Glob/Grep 工具探索项目
6. Claude 输出结构化 JSON
7. **复制 Claude 的 JSON 回复**

### 📋 粘贴 AI 回复（第二个标签页）

1. 切换到 **📋 粘贴 AI 回复** 标签
2. 将 Claude 输出的 JSON 粘贴到文本框
3. 点击 **🔍 提取到图谱**
4. 系统自动解析实体和关系，合并到当前图谱

也支持从自然语言中提取实体 — 包含文件路径、模块名等的文本也能被部分识别。

## 图谱交互

### 鼠标操作

| 操作 | 方式 |
|------|------|
| 缩放 | 鼠标滚轮 (以鼠标位置为中心) |
| 平移 | 按住空白区域拖拽 |
| 选择节点 | 单击节点 |
| 查看详情 | 单击节点 → 右侧弹出详情卡片 |

### 节点详情

点击节点后右侧弹出详情卡片，显示：
- 📝 **描述** — 实体的职责说明
- 🏷️ **属性** — 类型、文件路径、行号
- 🏷 **标签** — 自动分类标签
- 🔗 **关联关系** — 与之相关的所有其他实体，点击可跳转

### 图谱过滤

**类型过滤**（图谱视图左侧）：
- 点击类型图标芯片来筛选
- 支持多选，再次点击取消
- 「全部」显示所有类型

**搜索**（顶部搜索框）：
- 按名称、描述、标签搜索
- 实时过滤列表和标记载入图谱中

### 选中高亮

- 单击一个节点 → 该节点及直接关联的节点**高亮**
- 其余节点**变暗**（opacity 降到 12%）
- 点击空白区域或关闭详情卡片取消高亮

## 分析配置

点击 **⚙ 配置**（左侧栏或全屏图谱工具栏）打开配置对话框。

### 配置项

| 配置 | 默认值 | 说明 |
|------|--------|------|
| 📁 包含目录 | 空（全部） | 仅分析指定目录 |
| 🚫 排除目录 | node_modules, .git, dist, build, .next, .nuxt, __pycache__, .cache, .vscode, .idea, coverage, tmp, temp 等 | 排除的目录，支持 `*` |
| 📄 排除文件 | *.log, *.lock, *.map, *.d.ts, *.min.js, *.min.css 等 | 排除的文件名模式 |
| 🔤 排除扩展名 | .log, .svg, .png, .jpg, .woff 等 | 排除的文件后缀 |
| 🔍 内容关键词 | console.log, debugger | 含关键词的文件被排除 |
| 🧪 含测试目录 | ❌ | 是否分析 test/ 目录 |
| 📦 含 node_modules | ❌ | 是否分析 node_modules（很慢） |
| 🔒 含隐藏目录 | ❌ | 是否分析 . 开头的目录 |
| 📏 扫描深度 | 5 | 1-10 层 |

点击 **💾 保存并重新分析** 应用配置。

## 手动导入

### 从文件扫描导入

点击工具栏 **📥 导入** → 选择 **🔍 扫描项目**，手动触发文件扫描，覆盖当前图谱。

### 粘贴 JSON 导入

点击 **📥 导入** → 选择 **📋 粘贴 JSON**，手动粘贴 JSON 数据导入。

JSON 格式：
```json
{
  "entities": [
    {
      "id": "e1",
      "name": "用户模块",
      "type": "module",
      "description": "负责用户注册、登录、权限管理",
      "tags": ["user", "auth"]
    }
  ],
  "relations": [
    {
      "id": "r1",
      "sourceId": "e1",
      "targetId": "e2",
      "type": "depends_on",
      "label": "依赖"
    }
  ]
}
```

## 常见问题

### Q: 图谱很卡怎么办？

- 缩小视图（滚轮向下）减少可见节点
- 调整 **分析配置** → 增加排除目录/文件
- 减少扫描深度
- 关闭「包含测试目录」

### Q: 分析结果不准确？

- 使用 **📏 扫描深度** 控制扫描层数
- 使用 **📁 包含目录** 指定只分析核心目录
- 使用 **🤖 AI 分析** 让 Claude 做智能解析（比文件扫描更准确）

### Q: 如何增量更新图谱？

- 再次点击 **🔍 分析** 会重新扫描项目覆盖旧数据
- 使用 **🤖 AI 分析** → 粘贴 Claude 回复 → 结果是 **合并** 模式，不会删除已有实体
- 手动添加实体的 JSON 数据再导入（合并模式）

### Q: 图谱数据存储在哪里？

- 图谱数据：`~/.claude/projects/<encoded-path>/knowledge-graph/graph-data.json`
- 分析配置：`~/.claude/projects/<encoded-path>/knowledge-graph/analysis-config.json`

### Q: 不同的项目图谱相互独立吗？

是的，每个项目的图谱数据完全独立存储。
